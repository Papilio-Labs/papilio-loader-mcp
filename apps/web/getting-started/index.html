Getting Started With a Blank Board

Use this page once — the first time you set up a brand-new, never-flashed Papilio Retrocade. Everything happens in this browser tab over USB and your home WiFi. Nothing is installed on your computer, and your WiFi credentials never leave your machine except to the board itself.

Already set up? Come back here only to re-flash a board back to a blank state. For everyday use — JTAG SRAM, recovery mode, or OTA firmware updates — use the full Papilio Loader — Web Edition instead.

WebSerial isn't available in this browser. Open this page in Google Chrome or Microsoft Edge (desktop) over HTTPS to flash your board.
