Papilio Loader — Device Flash Manager

The same USB/Serial + OTA/WiFi flashing the Papilio Loader desktop app does, running entirely in this browser tab via WebSerial and direct network requests — nothing installed. First time setting up a board? The guided Flash page is a gentler start.

WebSerial isn't available in this browser. Open this page in Google Chrome or Microsoft Edge (desktop) over HTTPS.

Connect & Locate Device

Connect over USB for first-time setup or USB/Serial flashing. For OTA/WiFi flashing, the board needs its IP address — there's no browser-side network scan (like the desktop app's Discover Devices), so use Find My IP instead: it resets the board over USB and reads the IP it reports on boot, no physical RESET button press needed.

Device IP: unknown

This board switches to USB Host mode (for game controllers) a few seconds after boot, which disconnects the serial console. Hold USB Console saves a flag on the board (persists across reboots) that keeps the console alive instead; Resume USB Host clears it and brings USB Host mode up immediately.
