Papilio Loader — Device Flash Manager

The same USB/Serial + OTA/WiFi flashing the Papilio Loader desktop app does, running entirely in this browser tab via WebSerial and direct network requests — nothing installed.

WebSerial isn't available in this browser. Open this page in Google Chrome or Microsoft Edge (desktop) over HTTPS.

Connect & Locate Device

Connect over USB for first-time setup or USB/Serial flashing. For OTA/WiFi flashing, the board needs its IP address — there's no browser-side network scan (like the desktop app's Discover Devices), so use Find My IP instead: it resets the board over USB and reads the IP it reports on boot, no physical RESET button press needed.

Device IP: unknown

Board status (over WiFi): unknown — Resume Current App reboots into whatever's already flashed (no re-upload); Reboot to Loader switches to the loader so a new FPGA/ESP32 image can be flashed. If the board isn't reachable over WiFi at all, Recover via USB forces it back into the loader over USB — use this before Connect USB/Find My IP if the serial console is already open elsewhere on this page.

📟 FPGA Flash (Gowin)

No published core bitstream releases yet — upload a Gowin headerless .bin ("Binary File" export) from your own build.

SPI Flash survives a power cycle (the board briefly loads a small bridge bitstream first, then writes yours to the FPGA's own flash chip). JTAG SRAM is faster but lost on power cycle.

🔧 ESP32 Flash
