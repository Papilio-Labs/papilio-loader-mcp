Hosted Web Flasher

Flash Your Papilio Retrocade

Everything happens in this browser tab over USB and your home WiFi. Nothing is installed on your computer, and your WiFi credentials never leave your machine except to the board itself.

Already set up and want JTAG SRAM, recovery mode, or OTA firmware updates? Try the full Papilio Loader — Web Edition.

WebSerial isn't available in this browser. Open this page in Google Chrome or Microsoft Edge (desktop) over HTTPS to flash your board.

Flash ESP32 Firmware (USB)

      

      

        Download the latest -merged.bin from the
        FPGA-Companion releases page,
        plug your board in over USB, then flash. The merged image contains the bootloader, partition
        table, and app in one file — do not use the plain fpga_companion.bin from the release zip here.
        The board reboots itself automatically once flashing finishes — no button press needed.

        3
        
Flash FPGA Bitstream (WiFi or USB)

      

      

        Sent directly from this browser tab to the board — over WiFi if the device's IP is known
        (fastest), or over the same USB connection from Step 1/2 as a fallback if it isn't. No cloud
        relay either way. Only Gowin's headerless .bin ("Binary File") bitstream
        export is supported for either target below — .fs exports aren't parsed by
        the firmware yet. Recovery requires a known IP (WiFi OTA only for now).
